# Replaces almost all radio and golfcart songs with EFN, Die Very Rough and 4 Big Guys.
## Install
### Extract zip and run `install.bat`. This only works with default Steam install location. Otherwise manually replace audio banks with ones in zip. Requires restart of game.
--------
## Uninstall
### In the extracted folder, run `uninstall.bat`. Requires restart of game.
